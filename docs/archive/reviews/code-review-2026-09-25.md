## Checked and fine

What the reviewers examined and found sound, so the owner knows what was covered:

- **Injection.** The page's only HTML sinks are comrak's output (`unsafe_` off) and `json.rs`'s escaped output; every error, toast, tab, tree, title and update-note string goes through `textContent`. 350k fuzzed Markdown documents produced only allowed tags and attributes, no event handlers, no scripting URLs, no unquoted attributes; anchor recovery lets only the name through (`<a id="x"></a><script>` → `<span id="x">`). Themes go into `<style>` as text; the CSP blocks remote `@import`, `url()` and fonts; `valid_name` allows no traversal.
- **JSON.** 330k fuzzed documents and ~160k `more` clicks: no panic; the reflow never changes non-whitespace; markup stays nested in every chunk; every button's range is non-empty and on token boundaries; expanding everything reproduces the source exactly. 23 unusual shapes timed at 0.2 s or less, apart from the 32 MB one-line reflow (0.42 s). No quadratic behaviour left.
- **Markdown timing.** comrak is linear on the standard cmark pathological set at 200 KB–1.1 MB; 32 MB of plain text renders in 0.75 s. Only #4–#6 are pathological.
- **Rust core.** Every nested lock pair (no inversion, no std lock across an `.await`); the `CLOSE_WAIT` fallback and `closing` bookkeeping; main-thread-only saves; the update restart and failure paths; `write_box`; `repo_root` and the asset scope (stops at home and at drive and UNC roots; nothing can leave the machine); `natural_cmp` is a total order; session chain, offers, restore marks; watcher teardown; no `unwrap` on I/O or user data.
- **Frontend.** Path helpers run in node across UNC floors, drive roots, POSIX roots, percent-encoded separators and `#` in names; `showActive`'s token discipline; tab operations and `closedTabs`; the tree's epoch/keep bookkeeping; `folderBefore`; watcher key matching; `reportSoon`'s throttle and the close report; drag IPC ordering; the update flow's double-install guards; F5 in every spelling; boot listener order.
- **Updater and CI.** The minisign public key is pinned and matches 1.6.8's signatures; HTTPS endpoint, no `dangerous*` flags, strict version compare, deb/rpm refused. `contents: read` by default, no `pull_request_target`, no `github.event` in `run:`; every `uses:` SHA resolves to its commented tag; ssign pinned by `--rev --locked`; thumbprint and fingerprint checks on every signed artifact; tag and main rulesets block deletion and update; the `signing` environment is limited to `main` and `v*`. Dependabot alerts 0; secret scanning and push protection on.
- **Packaging.** NSIS hooks quote their paths and remove what they write; Linux postinst/postrm are best-effort; the MIME XML only adds globs.
